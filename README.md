Middle Messenger — это современный мессенджер. Описание проекта включает в себя основные функции, а также планы на будущее.

## Демо

Демо версия приложения доступна [здесь](https://gorgeous-ganache-d27c11.netlify.app/). Вы можете ознакомиться с возможностями и функциональностью приложения без необходимости его локальной настройки.

## Используемые технологии

- **TypeScript** ~5.6.2
- **Vite** ^5.4.10
- **Node.js** 16.20.2
- **Handlebars** ^4.7.8
- **Mocha** для тестирования
- **Chai** для утверждений в тестах
- **Sinon** для создания шпионов и моков в тестах

## 📖 Описание

На данном этапе реализованы несколько страниц приложения:
- Авторизация
- Регистрация
- Страница профиля (возможность отдельно изменять данные пользователя, пароль и аватар)
- Страничка чатов (подключен Websocket; реализована возможность просмотр чатов по id контакта, получения/отправления сообщений, добавления/удаления других юзеров в чат/из чата по логину, добавления/удаления чатов)
- Возможность добавления, изменения, удаления аватаров чатов
- Модальные окна с удалением и добавлением пользователей, загрузкой файла
- У всех полей форм реализована валидация

## 🚀 Запуск проекта

### Требования

- Node.js (https://nodejs.org/) версии 12 или выше
- NPM (https://www.npmjs.com/)

### Установка

1. Клонируйте репозиторий:

    ```git clone git@github.com:mary-an-safronova/middle.messenger.praktikum.yandex.git```
  

2. Перейдите в каталог проекта:

    ```cd middle.messenger.praktikum.yandex```
  

3. Установите зависимости:

    ```npm install```
  

4. Соберите проект:

    ```npm run build```

5. Запустите проект в режиме разработки:

    ```npm run start```

6. Откройте в браузере страницу:

    ```http://localhost:3000/```

### 🔍 Запуск тестов
Для запуска тестов выполните команду:
    ```npm run test```
Это запустит тесты, написанные с использованием Mocha и Chai.
